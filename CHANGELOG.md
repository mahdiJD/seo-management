# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-08-08

### Added

- SEO metadata management for Eloquent models.
- Route-based SEO management.
- Runtime SEO overrides.
- Global SEO defaults.
- Intelligent SEO resolution chain.
- SEO rendering with meta tags, Open Graph, Twitter Cards, and JSON-LD.
- SEO caching and automatic cache invalidation.
- SEO facade and Blade tags component.
- Filament v4 integration.
- `SeoManagerGroup` form component.
- `SeoRouteResource`.
- `SeoSettingsPage`.
- SEO cache clearing Artisan command.
